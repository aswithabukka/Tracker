# Aswitha Prep Tracker

Personal 6-week interview prep tracker. May 7 - June 17, 2026.

Live URL: (set after enabling GitHub Pages)

## Deploy to GitHub Pages

1. Create new public repo on GitHub (e.g. `prep-tracker`)
2. Upload `index.html` and this README
3. Settings → Pages → Source: `main` branch, root folder → Save
4. Wait ~1 minute. Tracker is live at `https://YOUR-USERNAME.github.io/prep-tracker/`
